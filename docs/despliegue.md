# Despliegue en Nube

1. Crear cuenta en Render, Vercel o Railway.
2. Conectar el repositorio GitHub.
3. Seleccionar el proyecto y el comando de inicio:
   ```bash
   npm start
   ```
4. Configurar la variable `PORT` si la plataforma lo requiere.
5. Desplegar y verificar el endpoint `/api/dashboard`.
